# Test implementation (ISTQB, summary)

- Test cases are arranged into test procedures and then into test suites. The order follows dependencies and priority, so the highest risk runs first.
- Test data and the test environment are prepared and verified before execution.
- Bidirectional traceability between the test basis, test conditions, test cases and procedures is checked.
- The time estimate in this application is a practical estimate from the number and complexity of steps, not a defined metric of the syllabus.
